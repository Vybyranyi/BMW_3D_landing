# BMW 330i F30 — лендинг

Одна сторінка про мою F30: 3D-модель, якою керує скрол (капот, двері, багажник, фари, дим з вихлопу),
паспорт з графіком B48, глобус з маршрутом Лос-Анджелес → Клайпеда → Чернівці і журнал відновлення.
Без бекенду й бази — чиста статика.

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # готовий сайт у dist/
```

`/viewer.html` (тільки в dev) — вільний огляд 3D-моделі мишкою з повзунками для дверей/капота/багажника.

## Що де міняти

| Що | Де |
| --- | --- |
| Усі тексти, дати, етапи відновлення, мод-лист, маршрут | `src/content.js` |
| Камера і що коли відкривається при скролі | `src/sections/showroom.js` (масиви `camera` і `tracks`) |
| Форма кузова (профілі, ширина, дах) | `src/three/car/profile.js` |
| Фари, ніздрі, ліхтарі, обвіс | `src/three/car/index.js`, `src/three/car/parts.js` |
| Кольори/матеріали | `src/three/car/materials.js` |
| Стилі | `src/styles.css` |

Фото у відновленні: поклади файли в `public/photos/` і додай до етапу `photos: ['photos/1.jpg', ...]`.

## Деплой

Будь-який статичний хостинг. Збірка відносна (`base: './'`), тож працює і в підпапці.

- **Vercel / Netlify**: імпортуй репозиторій, build command `npm run build`, output `dist`.
- **GitHub Pages**: зібрати й викласти `dist/` (наприклад, через `gh-pages` або GitHub Actions).
