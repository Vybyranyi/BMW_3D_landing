# BMW 330i F30 — лендинг

Одна сторінка про мою F30: 3D-модель, якою керує скрол (капот, двері, багажник, фари, дим з вихлопу),
паспорт з графіком B48, глобус з маршрутом Лос-Анджелес → Клайпеда → Чернівці і журнал відновлення.
Без бекенду й бази — чиста статика.

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # готовий сайт у dist/
```

`/viewer.html` (тільки в dev) — вільний огляд 3D-моделі мишкою з повзунками для дверей/капота/багажника.

## 3D-модель

Сайт вантажить `src/assets/models/f30.glb` (≈3.8 МБ, meshopt). Його зібрано з набору-конструктора
`bmw-3-series-f30-2011-2018/` (≈100 МБ, у git не потрапляє — лежить лише локально):

1. `tools/f30-config.js` — які деталі набору стоять на машині (бампер M Sport, сплітер і дифузор M Performance,
   «лезвія», чорні ніздрі, люк, чорна стеля, червоні ліхтарі, насадки вихлопу по обидва боки, спойлер…), куди їх зсунути і з чого вони зроблені.
2. `npm run dev` → `/inspector.html` — інспектор набору. У консолі: `previewConfig()` показує збірку,
   `exportConfig()` пише `tools/f30-selection.json`.
3. `node tools/build-model.mjs` — вирізає вибрані деталі, переводить у метри, групує (кузов, капот, багажник,
   4 двері, колесо), стискає та пише `src/assets/models/f30.glb`.

Матеріали (лак, скло, хром, червоні лінзи…) призначаються в `src/three/car/model.js` за назвою.
Якщо модель не завантажиться — сайт покаже запасну процедурну машину (`src/three/car/index.js`).

## Що де міняти

| Що | Де |
| --- | --- |
| Усі тексти, дати, етапи відновлення, мод-лист, маршрут | `src/content.js` |
| Камера і що коли відкривається при скролі | `src/sections/showroom.js` (масиви `camera` і `tracks`) |
| Комплектація моделі | `tools/f30-config.js` → `node tools/build-model.mjs` |
| Кольори/матеріали, шарніри, колеса | `src/three/car/model.js` |
| Стилі | `src/styles.css` |

Фото у відновленні: поклади файли в `public/photos/` і додай до етапу `photos: ['photos/1.jpg', ...]`.

## Деплой

Будь-який статичний хостинг. Збірка відносна (`base: './'`), тож працює і в підпапці.

- **Vercel / Netlify**: імпортуй репозиторій, build command `npm run build`, output `dist`.
- **GitHub Pages**: зібрати й викласти `dist/` (наприклад, через `gh-pages` або GitHub Actions).
